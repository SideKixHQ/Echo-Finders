# echofinders.com

The Echo Finders website: what it is, how it works, the prices, and the partner pitch.
Not the app (that is `apps/prototype`).

- Words and photos: `src/content.ts`. Keep prices in step with `PLANS` in `packages/core`.
- Run: `npm run dev --workspace @echofinders/site`.
- Deploys from `main` as its own Vercel project. See `DEPLOY.md`, "The website".
